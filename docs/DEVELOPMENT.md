v0.9 包含原照顾功能、随机活动、伸懒腰、追蝴蝶、玩小球、立式猫抓板、打哈欠及侧躺打滚露肚皮。后两项已经实现，不应当成新增待办再次开发。

## 验证边界

历史 `source/validation.txt` 和 `source/*results.json` 是恢复时保留的旧检查记录，部分正文停留在 v0.8 或更早阶段；不代表本轮已验证。新的 Canvas 报告在 `qa/`，GitHub 验证以 Actions 实际运行结果为准。

Linux 上可检查 JS 状态、Canvas 实际像素、共享时间表和静态构建；此环境不能直接运行 WPF。Windows 自动自测会生成 13 种活动图、64 张动作截图及 6 张连续磨爪截图，覆盖资源/状态/存档和离屏渲染，仍不覆盖真实托盘、透明窗口、鼠标操作及 Windows 智能应用控制。

用户已报告 Windows 智能应用控制拦截 `Start-Rousong.cmd`。当前源码使用本机 csc 编译未签名 EXE；本轮不将“能自动编译”等同于“用户电脑已能启动”。
